# 우나르메 디스코드 봇
## 얘 뭐임?
> (입력: 우나르메야 요구르트) => **어디요?! 저도 먹을래요!**
- 아직 컨셉이 명확하게 안 잡힌 디스코드 봇 (캐릭 설정은 로리 안드로이드로 갈 생각이긴 함)  
- 일단은 내가 있으면 좋을 것 같다 싶은 기능들 이것저것 잡탕으로 추가하는 중
- 곧 구글 클라우드인가 그거 해서 간단히 호스팅 할 예정
- DB로는 MongoDB의 무료플랜 사용중임
- ~~내가 돈이 많았다면 AI 채팅을 뿌리는데 말야 ㅠㅠ~~

## 수집하는 정보
- 로그에 아래 내용이 출력되는데, 전 로그를 저장해둡니다. (봇 관리용 디스코드 서버의 로깅용 채널에도 로그를 실시간으로 전송함)
- **명령어 사용한 기록** (슬래시커맨드 option에 입력한 내용, 사용자 디스코드 아이디)
- **봇이랑 채팅한 내역** (입력한 채팅의 내용, 사용자 디스코드 아이디)

## 사용법
### 대화
- Prefix: '우나르메야'
- 뒤에 문장을 입력하든 단어를 입력하든 감지해서 반응함
- '우나르메야 공식대화모음' 을 입력해 내가 미리 입력해둔 대화목록 볼 수 있음
- 참고로 봇이 있는 모든 채널에서 반응하니 주의해주십쇼
### 슬래시커맨드
#### 배워
- 우나르메에게 대화할 단어를 가르치는(DB에 저장하는) 명령어
- 정규식 지원함 (아래 코드박스 참조)
```
{choice:'a'|percent,'b'|percent,'c'|percent} a, b, c를 각각의 확률에 따라 답변합니다. 전부 확률을 적지 않으면 균등확률로 답변합니다.
{mention} 채팅을 입력한 사람을 멘션합니다.
{br} 채팅 하나 안에서 줄을 바꿉니다.
{rand(a, b)} a~b 사이 정수를 랜덤으로 출력합니다.
{wait:x} 이 태그를 기준으로 앞 뒤가 다른 채팅으로 나뉘며, 이 태그 앞 메시지 전송 후 x초 기다린 후 뒤의 내용이 전송됩니다.
```
#### 잊어

#### 학습목록
- 방금 설명함 ㅇㅇ
#### 애니검색
- Anilist.co라는 좋은 사이트에서 애니 정보를 검색해 엠베드로 출력해줌
- 추천애니 목록 기능 있음 (인간지능이라 생각보다 정확도 높음)
#### 미연시검색
- 말만 미연시검색이지 사실상 비쥬얼노벨 전부 다 검색 가능 (물론 vndb.org에 존재한다는 가정 하에)
- 3단계 스포일러 처리 지원
```
1단계(스포일러 없음): 그냥 표시
2단계(마이너 스포일러): 스포일러 처리, 버튼 누른 경우 그냥 표시 
3단계(메이저 스포일러): 미표시, 버튼 누른 경우 스포일러 처리
```
- 설명에 html 태그 재처리 지원
- nsfw 관련은 일반 채널에서 아예 미표시되니 떡겜이나 고어겜 검색은 nsfw채널에서 해주십쇼
- 제목에 그 비쥬얼노벨 vndb 링크 달아 둠
